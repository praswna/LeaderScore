# LeaderScore 콘텐츠 작성 기준

LeaderScore는 역사 속 지도자의 업적(공, +)과 과오(과, −)를 사건별 점수로 매기는 앱이다.
종합점수 = 사건 점수의 단순 합. 화면은 한국어.

## 출력 형식

`data/<그룹>.json` — 지도자 배열. 반드시 유효한 JSON(주석·후행 쉼표 금지).

```json
[
  {
    "id": "sejong",
    "name": "세종",
    "country": "한국",
    "dynasty": "조선",
    "role": "군주",
    "start": 1418,
    "end": 1450,
    "summary": "한두 문장 총평.",
    "events": [
      { "year": 1443, "title": "훈민정음 창제", "description": "한 문장 설명", "score": 10, "reason": "한 문장 근거" }
    ]
  }
]
```

- `id`: 영문 소문자·숫자·하이픈. 전체에서 고유하게 (예: `taejo-joseon`, `taizong-tang`).
- `name`: 한국에서 통용되는 이름 (예: "태종 이세민", "에이브러햄 링컨").
- `country`: 반드시 다음 중 하나 — 한국, 중국, 일본, 미국, 유럽, 러시아, 기타.
- `dynasty`: 2단 탭 이름. 한국·중국은 왕조/시대명, 일본은 시대명(아스카, 센고쿠, 에도, 메이지, 쇼와 등), 유럽·기타는 나라명(프랑스, 영국, 몽골 …), 미국은 빈 문자열.
- `role`: 아래 중 하나를 고른다.
  - 통치자: 군주, 황제, 천황, 쇼군, 칸, 술탄, 파라오, 대통령, 총리, 주석, 총통, 실권자, 섭정
  - 관료: 재상, 장군, 관료, 통감, 총독, 총리대신(군주 아래의 총리)
  - 사상·운동: 사상가, 독립운동가, 혁명가, 운동가
- `start`/`end`: 재위·재임(관료는 주요 활동) 시작·끝 연도. 기원전은 음수.
- `events`: 3~8개 (기록이 적은 인물만 3개). 시간순. 연도는 실제 연도(기원전 음수).
- `score`: −10 ~ +10 정수, **0 금지**.
- `description`, `reason`, `summary`: 담백한 한국어 평서문. 한 문장(총평은 1~2문장).

## 채점 기준 (모든 작성자 공통 — 일관성이 가장 중요)

사건이 **그 나라 사람들과 인류에게 끼친 실제 영향**을 당대·장기 영향을 함께 고려해 평가한다.

| 점수 | 의미 | 예 |
| --- | --- | --- |
| ±9~10 | 문명·국가 차원에서 수백 년 이어지는 결정적 영향 | 훈민정음 창제 +10, 노예해방선언 +10, 홀로코스트 −10 |
| ±7~8 | 국가 전체에 큰 영향, 오래 지속 | 후삼국 통일 +9, 한일병합조약 체결 −10, 대규모 학살·숙청 −8 |
| ±4~6 | 분명하고 상당한 영향 | 제도 개혁, 주요 전쟁 승패, 대형 토목사업 |
| ±1~3 | 제한적·일시적 영향 | 상징적 조치, 작은 실책 |

- **균형:** 사료로 뒷받침되는 공과 과를 모두 넣는다. 성군에게도 과가, 폭군에게도 (있다면) 공이 있다. 억지로 만들지는 않는다.
- **사실성:** 실제로 있었던, 교과서·백과사전 수준에서 확인 가능한 사건만. 연도를 정확히. 확신이 없는 사건은 넣지 않는다.
- **중립:** 특정 정치 성향의 수식어를 쓰지 않는다. 학계에서 논쟁 중인 평가는 근거에 "논란이 있다"처럼 쓰지 말고, 확인된 사실과 결과를 기준으로 점수를 매긴다.
- 사건 하나는 하나의 행위·결정. 같은 일을 두 번 세지 않는다.
- 지도자의 재위 전 사건도 그 인물의 핵심 행적이면 포함 가능 (예: 쿠데타로 집권).
- **생존 인물은 넣지 않는다.**
- **사상가·운동가:** 사상 자체가 아니라 그 사상과 활동이 실제로 끼친 영향을 사건으로 쓴다 (저술 간행, 학파 형성, 국가 이념으로 채택, 의거·무장 투쟁, 단체 결성, 변절·협력 등). `start`/`end`는 주요 활동 기간.

## 사건 분야 (`category`)

사건마다 아래 5개 중 **점수가 주로 반영하는 측면** 하나를 고른다.

| 분야 | 해당 |
| --- | --- |
| 경제 | 재정·세제·화폐·토지제도·산업·무역·농업, 경제 목적의 토목(운하·도로) |
| 외교·안보 | 전쟁·전투·정벌·침략·방어, 군 제도·국방, 조약·동맹·수교·사절·국제 협상, 국권을 넘긴 조약 |
| 인권·민생 | 학살·대량 처형·사화·종교 박해·탄압·강제 노동, 노예·신분제, 복지·구휼·기근 대응, 차별 |
| 문화·학문 | 문자·편찬·교육·과학·기술·예술·종교 진흥, 상징적 건축 |
| 정치·제도 | 건국·즉위·집권·쿠데타(군대를 동원했어도)·개헌·관제·법전·행정구역·권력 구조·선거·부패·정적 숙청(소수 고위층) |

- 정적·고위층 소수의 숙청은 정치·제도, 민간인·다수의 희생이 중심이면 인권·민생.
- 침략 전쟁은 외교·안보. 그 과정의 학살이 별도 사건이면 인권·민생.
- 자국 정권을 뒤엎은 쿠데타는 군대를 썼어도 정치·제도.
